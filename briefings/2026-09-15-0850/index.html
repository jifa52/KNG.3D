לפי Alpha Signal (11 בספטמבר), DeepSeek השיקה את V4.1-Flash: מודל MoE עם כ־552 מיליארד פרמטרים, שמפעיל רק כ־8B בקריאת הקלט ו־16B בכתיבת הפלט. לפי הדיווח הוא עוקף את V4-Pro במהירות, עלות וביצועים — ולכן V4-Pro יוצא לגמלאות. המודל רואה תמונות באופן מובנה, מדורג #1 ב־Terminal-Bench 2.1 מול Claude Opus 5 ו־GPT-5.6 לפי הדיווח, והמטמון (KV) דורש כ־4× פחות RAM ו־8× פחות אחסון. תמחור מחוץ לשעות השיא זול ב־50%; ב־API השם הוא deepseek-flash (שמות ישנים מנותבים אליו).

Per Alpha Signal (Sep 11), DeepSeek shipped V4.1-Flash: a ~552B MoE model that activates only ~8B parameters on input and ~16B on output. The write-up says it beats V4-Pro on speed, cost, and performance — so V4-Pro is being retired. It sees images natively, ranks #1 on Terminal-Bench 2.1 ahead of Claude Opus 5 and GPT-5.6 per the report, and needs ~4× less RAM and ~8× less storage for the KV cache. Off-peak pricing is cut 50%; the API name is deepseek-flash (old names still route there).

The point: AI has erased the skill gap that once separated state hackers from lone criminals. Every described operation was disrupted, safeguards tightened, and intelligence shared with authorities.

DeepSeek: מודל כמעט כפול בגודל — עם מטמון KV קל פי ארבעה

DeepSeek’s efficiency playbook: nearly 2× bigger model, 4× lighter KV cache

ב־Sunday Deep Dive של Alpha Signal (13 בספטמבר) פורט איך V4.1-Flash (יצא 10 בספטמבר) מפריד קיבולת מעלות הגשה: כמעט כפול מגודל V4-Flash אך עם כ־890 בתים לטוקן במטמון KV לעומת ~3,514 ב־V4-Flash. ארכיטקטורת Causal Encoder-Decoder (20 שכבות קידוד + 20 פענוח) מפעילה רק 8B על קלט ו־16B על פלט; Sliding-Window Attention עם Bounded Replay מצמצם שחזור מצב מקומי; Compressed Sparse Attention 2 משתף זיכרון היסטורי בין שכבות; ואינדקס היררכי מגביל את עלות החיפוש בחלון של עד מיליון טוקנים. לפי הדיווח זה כרבע מדרישת HBM של V4-Flash ושמינית מאחסון SSD של המטמון — קריטי לסוכנים עם הקשר ארוך.

In Alpha Signal’s Sunday Deep Dive (Sep 13), V4.1-Flash (released Sep 10) separates model capacity from serving cost: nearly twice V4-Flash’s size yet ~890 bytes of KV cache per token vs ~3,514 for V4-Flash. A Causal Encoder-Decoder (20 encoder + 20 decoder layers) activates only 8B on input and 16B on output; Sliding-Window Attention with Bounded Replay cheaply rebuilds local state; Compressed Sparse Attention 2 shares historical memory across layers; a hierarchical indexer bounds search cost over up to a million-token window. The write-up pegs HBM need at ~¼ of V4-Flash and SSD cache storage at ~⅛ — decisive for long-running agents.

למה זה חשובWhy it matters

מספר הפרמטרים כבר לא מנבא עלות — מה שקובע הוא כמה זיכרון הקשר נשאר חי בין קריאות סוכן.

Parameter count no longer predicts cost — what matters is how much context memory stays alive between agent calls.
