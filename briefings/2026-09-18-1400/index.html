Four commodity ships transited Hormuz on Thursday — still under the 10-day average — as three LNG carriers reappear outside the strait

Reuters (סינגפור, 18 בספטמבר): נתוני Kpler ראשוניים ב־02:00 GMT — ארבע ספינות סחורות (commodity vessels) עברו במיצר הורמוז (Strait of Hormuz) ביום ה׳ (שלוש נכנסות, אחת יוצאת), ירידה משש ביום הקודם, מתחת לממוצע עשרת הימים של כ־16. התמהיל: שני פנמקס (Panamax), סופרמקס (Supramax) אחת, קמסרמקס (Kamsarmax) אחת. הספרות עלולות להשתנות: חלק מהספינות מכבות משדרים (transponders). בנפרד, שלוש נושאות LNG (גז טבעי נוזלי) הופיעו מחדש מחוץ למיצר ביום ה׳ (Al Daayen, Al Samriya, Marigold LNG). מיצר באב אל-מנדב (Bab el-Mandeb): 23 ביום ה׳ מול ~26 בממוצע עשרת הימים. ספירת יום ה׳, לא שלוש של יום ד׳, ולא טענת IRGC מהלילה.

Reuters Singapore Sept 18: preliminary Kpler at 02:00 GMT — four commodity vessels transited the Strait of Hormuz (מיצר הורמוז) Thursday (three in, one out), down from six a day earlier, below a 10-day average of about 16. Mix: two Panamax (פנמקס), one Supramax (סופרמקס), one Kamsarmax (קמסרמקס). Figures could change: some ships switch off transponders (משדרים). Separately, three LNG (גז טבעי נוזלי) carriers reappeared outside the strait Thursday (Al Daayen, Al Samriya, Marigold LNG). Bab el-Mandeb (מיצר באב אל-מנדב): 23 Thursday vs ~26 ten-day average. Thursday’s count, not Wednesday’s three, and not the overnight IRGC claim.

Claude adds Docs, Slides & Design — a full productivity suite inside one chat

The write-up says you can go from a one-pager to a deck to a matching visual in one chat, with no copy-paste between apps. Tasks can keep running after you close the laptop; if Claude hits a wall, it asks. Prior Cowork chats, projects, and files remain. Rolling out to Pro and Max soon, per the report.

Salesforce in Claude — 37 built-in CRM sales skills in open beta

לפי Alpha Signal (16 בספטמבר), האינטגרציה ״Salesforce in Claude״ נפתחה בביטא פתוחה: Claude מושך נתוני Salesforce חיים ופועל עליהם מתוך חלון הצ׳אט. 37 skills (מיומנויות מוכנות מראש) מכסות משימות מכירה נפוצות — הכנה לשיחה עם היסטוריית חשבון ועסקאות, בדיקת בריאות דִיל וסטטוס pipeline (צינור מכירות), עדכון רשומות ומשלוח תחזיות בשפה טבעית. אדמין אחד מחבר פעם אחת וכל הצוות מקבל גישה; ההרשאות יורשות מתפקידי Salesforce הקיימים, כך ש־Claude לא רואה מה שהמשתמש לא יכול לראות ב־CRM. לפי הדיווח, skills לשירות, שיווק ומסחר מתוכננים בהמשך השנה.

Per Alpha Signal (Sep 16), “Salesforce in Claude” opened in open beta: Claude pulls live Salesforce data and acts on it inside the chat window. Thirty-seven pre-built skills cover common sales tasks — call prep with account and deal history, deal-health and pipeline review, record updates and forecasts in plain language. One admin connects once and the whole team gets access; permissions inherit from existing Salesforce roles, so Claude cannot see anything a user could not already see in the CRM. Skills for service, marketing, and commerce are planned later this year, per the report.

The CRM moves into the conversation — fewer screen hops, more action on live data.

Odyssey-3 — מודל עולם אחד לשליטה ברובוטים, מכוניות ורחפנים (וגם לאימון AI אחר)

Odyssey-3 — one world model that steers robots, cars, and drones (and trains other AIs)

לפי Alpha Signal (16 בספטמבר), Odyssey שיחררה את Odyssey-3: מודל עולם (world model — מודל שלומד איך הסביבה הפיזית מתנהגת) עם backbone (עמוד שדרה משותף) אחד ומתאמים קלים לכל משימה. לפי הדיווח הוא שולט ברובוטים, דמויי־אדם, מכוניות, רחפנים ודמויות משחק; מייצר עולמות סימולציה אינטראקטיביים לאימון; ומדווח על העברת sim-to-real (אימון בסימולציה ופריסה בעולם האמיתי) של כ־77% מביצועי נהיגה אמיתיים בכבישי הודו. אפשר לאמן סוכנים בעולמות שנוצרו ב־AI — לולאת שיפור עצמי. גישה ציבורית דרך פורטל מפתחים צפויה תוך שבועות לפי הדיווח.

Per Alpha Signal (Sep 16), Odyssey released Odyssey-3: a world model (a model that learns how the physical environment behaves) with one shared backbone and lightweight task adapters on top. The write-up says it steers robots, humanoids, cars, drones, and game characters; generates interactive simulated worlds for training; and reports sim-to-real transfer (train in simulation, deploy in the real world) at about 77% of real-world driving performance on Indian roads. Agents can train inside AI-generated worlds — a self-improving loop. Public access via a developer portal is coming within weeks, per the report.

מוח שליטה אוניברסלי מפחית את הצורך לאמן מודל נפרד לכל רובוט או רכב.

A universal control brain cuts the need to train a separate model for every robot or vehicle.

LongCat-Video-Avatar 1.5 — אווטאר מדבר בקוד פתוח מתמונה אחת וקובץ אודיו

LongCat-Video-Avatar 1.5 — free open-source talking avatar from one photo + audio

לפי Alpha Signal (16 בספטמבר; חזר גם ב־17), Meituan שיחררה את LongCat-Video-Avatar 1.5 תחת רישיון MIT: מזינים תמונת דיוקן וקובץ אודיו ומקבלים וידאו מדבר מסונכרן שפתיים. לפי הדיווח אפשר להריץ שני דמויות באותו סצנה עם רצועות אודיו נפרדות, לייצר ב־480p או 720p עם זהות יציבה בקליפים ארוכים, וגם מצב טקסט בלבד בלי תמונה. התיקון הגדול ב־v1.5: מעבר ל־Whisper-Large (מודל דיבור/תמלול) כדי שתנועות הפה יתאימו למילים. הפשרה: אחסון עצמי דורש GPU של כ־40GB וזמן חישוב של כ־44 שניות לכל שנייה של וידאו. המשקלים ב־Hugging Face.

Per Alpha Signal (Sep 16; also flagged Sep 17), Meituan shipped LongCat-Video-Avatar 1.5 under an MIT license: feed a portrait photo and an audio file, get a lip-synced talking-head video. The write-up says it can run two characters in one scene on separate audio tracks, generate at 480p or 720p with stable identity on long clips, and offer a text-only mode with no photo. The big v1.5 fix: it swaps in Whisper-Large (a speech/transcription model) so mouth motion matches the words. Tradeoff: self-hosting needs ~40GB GPU and about 44 seconds of compute per second of video. Weights on Hugging Face.

Talking avatars move from paid SaaS to an open-source repo — if you have the GPU.

DeepMind Dream-RSI — סוכן שמשפר את עצמו ומוריד עלויות חיפוש AI עד פי 162

DeepMind Dream-RSI — a self-improving agent that cuts AI search costs up to 162x

לפי Alpha Signal (17 בספטמבר), Google DeepMind הציגה את Dream-RSI: במקום אסטרטגיית חיפוש קבועה ויקרה לעדכון בזמן אמת, המערכת משחזרת ניסיונות ישנים — כמו מאמן שצופה במשחק מוקלט במקום אימון חדש — מדמה אלפי גישות חלופיות מההיסטוריה, בוחרת את הטובה ופורסת אותה. לפי הדיווח זה עובד על עיצוב אלגוריתמים, אופטימיזציה מתמטית והנדסת GPU, ומוריד קריאות ל־AI עד פי 162 במקרים מסוימים. הנקודה החשובה: לא משנים את המודל הבסיסי — רק איך הוא חוקר. אפשר להוסיף על סוכן קיים בלי אימון מחדש.

Per Alpha Signal (Sep 17), Google DeepMind showed Dream-RSI: instead of a fixed search strategy that is expensive to update live, the system replays old attempts — like a coach reviewing game film instead of a new practice — simulates thousands of alternative approaches from history, picks the best, and deploys it. The write-up says it works across algorithm design, math optimization, and GPU engineering, and cuts AI calls by up to 162x in some settings. Key point: it does not change the underlying model — only how it explores. You can drop it on an existing agent without retraining.

למה זה חשובWhy it matters

עידן היעילות: סוכן חכם יותר בחיפוש — בלי לאמן מודל חדש בכל פעם.

The efficiency era: smarter search for the agent — without retraining a new model each time.

Meta Muse — סוכן אישי שנבנה מתוך הנחה שהזרקת פרומפט תצליח

Meta Muse — a personal agent built assuming prompt injection will succeed

לפי The Batch של DeepLearning.AI (18 בספטמבר), Meta השיקה את Muse — סוכן אישי על מודל Muse Spark 1.3 (אפליקציה / WhatsApp) שקורא ושולח מיילים, גולש, ממלא טפסים ומבצע רכישות גם כשהאפליקציה סגורה. ארה״ב בלבד, 18+, חינם עד כ־100M טוקנים לשבוע ואז שכבות $20 / $100. הארכיטקטורה הביטחונית: כל סוכן רץ ב־VM מבודד; אזור runtime חתום מטפל בנתונים לא־מהימנים בלי סיסמאות; שירות credentials חיצוני ו־Sentinel מאשרים כל בקשה ומחליפים טוקנים אמיתיים רק ביציאה; אישורים קריטיים (מייל/רכישה) דרך דיאלוג מערכת באפליקציה — לא כהודעה בשיחה שניתן לזייף. שכבות נוספות: תיוג תוכן לא־מהימן, מסווגים מחוץ לתא, ובדפדפן קריאת עץ נגישות במקום קוד העמוד. Meta לא פרסמה מדדי דיוק למסווגים; יש באג־באונטי עד $300K / $130K להזרקת פרומפט.

Per DeepLearning.AI’s The Batch (Sep 18), Meta launched Muse — a personal agent on Muse Spark 1.3 (app / WhatsApp) that reads and sends email, browses, fills forms, and makes purchases even with the app closed. U.S. only, 18+, free up to ~100M tokens/week then $20 / $100 tiers. Security architecture: each agent runs in an isolated VM; a sealed runtime cell handles untrusted data with no passwords; an external credential service plus Sentinel approve each request and swap in real tokens only on the way out; critical approvals (email/purchases) arrive as system dialogs in the app — not as forgeable chat messages. Extra layers: untrusted-data labels, out-of-cell classifiers, and browser reading of the accessibility tree instead of page code. Meta did not publish classifier accuracy metrics; bug bounty up to $300K / $130K for a successful prompt injection.

Agent security moves from model instructions to OS-level controls — because the model is assumed to fail.
