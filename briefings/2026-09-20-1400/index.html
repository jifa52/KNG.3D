DeepMind Dream-RSI — סוכן שמשפר את עצמו ומוריד עלויות חיפוש AI עד פי 162

DeepMind Dream-RSI — a self-improving agent that cuts AI search costs up to 162x

לפי Alpha Signal (17 בספטמבר), Google DeepMind הציגה את Dream-RSI: במקום אסטרטגיית חיפוש קבועה ויקרה לעדכון בזמן אמת, המערכת משחזרת ניסיונות ישנים — כמו מאמן שצופה במשחק מוקלט במקום אימון חדש — מדמה אלפי גישות חלופיות מההיסטוריה, בוחרת את הטובה ופורסת אותה. לפי הדיווח זה עובד על עיצוב אלגוריתמים, אופטימיזציה מתמטית והנדסת GPU, ומוריד קריאות ל־AI עד פי 162 במקרים מסוימים. הנקודה החשובה: לא משנים את המודל הבסיסי — רק איך הוא חוקר. אפשר להוסיף על סוכן קיים בלי אימון מחדש.

Per Alpha Signal (Sep 17), Google DeepMind showed Dream-RSI: instead of a fixed search strategy that is expensive to update live, the system replays old attempts — like a coach reviewing game film instead of a new practice — simulates thousands of alternative approaches from history, picks the best, and deploys it. The write-up says it works across algorithm design, math optimization, and GPU engineering, and cuts AI calls by up to 162x in some settings. Key point: it does not change the underlying model — only how it explores. You can drop it on an existing agent without retraining.

Meta Muse — a personal agent built assuming prompt injection will succeed

Per DeepLearning.AI’s The Batch (Sep 18), Meta launched Muse — a personal agent on Muse Spark 1.3 (app / WhatsApp) that reads and sends email, browses, fills forms, and makes purchases even with the app closed. U.S. only, 18+, free up to ~100M tokens/week then $20 / $100 tiers. Security architecture: each agent runs in an isolated VM; a sealed runtime cell handles untrusted data with no passwords; an external credential service plus Sentinel approve each request and swap in real tokens only on the way out; critical approvals (email/purchases) arrive as system dialogs in the app — not as forgeable chat messages.
